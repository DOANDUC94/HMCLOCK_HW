Trình Mô Phỏng & Cân Chỉnh Toạ Độ Font (Góc Trên Bên Trái)

Nạp font TTF, nhập Size, tọa độ Y được tính từ đỉnh góc trên bên trái của ký tự (Top-Left Origin).

1. Nạp File / Thư Mục Font

Kéo thả file font hoặc Click chọn 1 File
Đi tới font số: (0 font)
Sử dụng Font hệ thống mặc định (Arial)

2. Tham Số Kích Thước

3. Cân Chỉnh Tọa Độ (Top-Left Y)

Khoảng cách từ gốc X đến cạnh trái bounding box
Khoảng cách từ gốc Y đến đỉnh trên bounding box
Khoảng cách nhảy bước x sau mỗi ký tự

Màn Hình Mô Phỏng (Giả lập E-Ink)

Kích thước màn hình:

Thông Số Ký Tự Đầu Tiên Định Hướng Top-Left:

Độ rộng pixel thực tế (bw): -
Chiều cao pixel thực tế (bh): -
Offset X mặc định (bx): -
Offset Y mặc định từ đỉnh (by): -
Khoảng cách bước nhảy (advance): -
Nguyên lý hệ tọa độ mới:
- Điểm chấm Đỏ là điểm gốc ký tự đầu tiên (Top-Left Origin).
- Điểm chấm Xanh là góc trên cùng bên trái của khung ma trận chứa dữ liệu chữ thực tế (Bounding Box).
- Trục Y giờ đây hướng thẳng xuống dưới. Toàn bộ logic hiển thị này tương thích hoàn toàn với hệ điều hành đồ họa LCD/E-Ink thông dụng.
